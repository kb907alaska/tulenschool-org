# Tułen Charter School (`tulenschool.org`)

[![Live Demo](https://img.shields.io/badge/Live%20Dev%20Site-https%3A%2F%2Ftulenschool--org.pages.dev%2F-0F4C5C?style=for-the-badge&logo=cloudflare)](https://tulenschool-org.pages.dev/)

> **Live Dev Preview**: [https://tulenschool-org.pages.dev/](https://tulenschool-org.pages.dev/)

Tułen Charter School is a public K-4 charter school located in Kenai, Alaska, operated in partnership between the **Kenai Peninsula Borough School District (KPBSD)** and the **Kenaitze Indian Tribe**.

---

## 🌲 About Tułen Charter School

- **Location**: Kahtnuht’ana Duhdeldiht Campus, 12271 Kenai Spur Highway, Kenai, AK 99611
- **Phone**: (907) 335-2829
- **Grade Levels**: Public K-4 Elementary
- **Dena'ina Name Meaning**: *Tułen* — "The river will flow" / "The current is flowing"
- **Pillars**:
  - Dena'ina Language & Cultural Heritage
  - Outdoor Subsistence & River Ecology Science
  - Foundational Literacy & STEAM Excellence
  - Family, Elder & Tribal Governance Partnership

---

## 🚀 Built with Astro 7

This website is engineered with **Astro 7**, **React**, **Tailwind CSS v4**, and **Lucide Icons**:

- **Fast Static Delivery**: Pre-rendered pages for optimal performance and SEO.
- **Interactive UI Wizards**: K-4 Online Enrollment Form and Calendar Event Filtering powered by React.
- **Full Parity**: Complete site layout, staff directory, APC governance documents, monthly newsletter archives, parent resources, and mobile drawer navigation.

## 🧞 Local Development & Build Commands

```sh
# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
